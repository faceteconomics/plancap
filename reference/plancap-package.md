# plancap: plan-enabled development capacity from planning rules and parcels

plancap estimates the floorspace and dwellings that planning rules
enable on each land parcel. It is written to be independent of any one
jurisdiction: the rules are data (a *rulebook*), not code.

## Scope

Results are **plan-enabled, gross, blank-slate** capacity: what the
rules would allow if no buildings existed. They are not estimates of
feasible, infrastructure-ready or likely development.

## Example data

[`exampleton()`](https://faceteconomics.github.io/plancap/reference/exampleton.md)
loads a synthetic town built to exercise every rule type. It is
deliberately placed offshore so it cannot be mistaken for a real place.
